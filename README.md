# MovieGrisha

A simple movie discovery web application built with React and TypeScript.

The project was created to practice building a frontend application from scratch, working with an external API, managing asynchronous data, and building a responsive user interface.

## Demo

[Live Demo](https://moviegrisha.vercel.app/)

## Features

* Search for movies
* Browse movie results
* View movie information
* Responsive layout
* Loading and error states
* Client-side routing

## Tech Stack

* React
* TypeScript
* React Router
* Vite
* CSS
* REST API

## Getting Started

### Requirements

* Node.js
* npm

### Installation

```bash
git clone https://github.com/GreaterBerg/MovieGrisha.git
cd MovieGrisha
npm install
```

### Development

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite.

### Build

```bash
npm run build
```
